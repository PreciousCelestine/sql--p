# AdventureWorks SQL Analysis

A SQL learning project exploring product, employee, customer
and sales data in Microsoft's AdventureWorks sample database.

## Tools
- Microsoft SQL Server
- Transact-SQL (T-SQL)
- AdventureWorks OLTP sample database

## Project scope
The repository contains 16 SQL exercises covering:
- Product filtering and segmentation
- Employee and employment-date analysis
- Joins across customer, employee and sales tables
- Aggregation and distinct counts
- Pricing and commission calculations
- Window functions and reporting views

## Files
- SQLQuery PROJECT.sql: exercise questions and SQL queries

## Status
The SQL queries are undergoing review and correction.
The script has not yet been validated from start to finish.

## Data
AdventureWorks is a sample database. This is an educational
project, not a client implementation.
